# Мой маршрут — персональный трекер преподавателя

Учебный прототип для проекта Language Link. Авторские памятки не являются официальной программой школы.

## Как открыть

Скачайте `teacher-tracker.html` и откройте его в браузере — установка не нужна. Для размещения на любом статическом хостинге используются `index.html`, `style.css`, `app.js` из этой папки.

## Что работает

- Самооценка по трём актуальным задачам: инструкции, обсуждение, цель урока.
- Рекомендация по выраженной потребности. Стаж не определяет направление; пользователь может выбрать другое.
- Собственный план: цель, критерий наблюдения, дата пробы и материал.
- Три встроенные практические памятки и отметки подготовки.
- Дневник: действие, факт по критерию, следующий шаг. История сохраняется при смене направления.
- Учебные профили Анны и Марии; их записи отделены от собственного маршрута.
- Сохранение в браузере, экспорт и импорт JSON, печать.

## Хранение

Данные остаются только в localStorage текущего браузера. Общего кабинета наставника, регистрации и синхронизации между устройствами в этой версии нет. Для переноса используйте «Сохранить в файл» и «Загрузить из файла». Не храните имена учеников в наблюдениях.

## Проверка

Проверены в браузере самооценка, сохранение плана и дневника после перезагрузки, влияние стажа на выбор. Проверены форма импортируемых данных и отделение старого наблюдения от новой цели. Процент шагов показывает заполнение маршрута, а не качество преподавания.
